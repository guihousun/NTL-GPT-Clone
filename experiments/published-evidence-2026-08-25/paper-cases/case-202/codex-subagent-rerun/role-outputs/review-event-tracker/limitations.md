# Limitations and non-claims

> Codex-subagent simulation. These limits apply to this review and to any handoff that cites it.

1. This output is a read-only review of existing case assets. It does not prove
   that the deployment NTL-GPT, Deep Agents, a four-role runtime, or any model
   provider executed this review.
2. The review is not part of benchmark-v1 and supplies no benchmark score,
   accuracy, ablation, Full-versus-Single-Agent comparison, or runtime
   performance evidence.
3. Q18's event identity is bounded by the supplied official-domain search
   snapshots and the explicitly identified derived reference. The review did
   not perform a live web refresh or download source records.
4. Q18's local timestamp is `12:50:52+06:30` in `Asia/Yangon`; the first
   post-event local-night label is derived from the UTC product-date convention.
   HDF metadata do not expose an exact pixel acquisition time.
5. Q18's 25 km and 50 km results have opposite directions and different valid
   pre-event sample sizes. They are separate descriptive support checks, not a
   pooled or scale-robust event effect.
6. Q18 has only one interpreted first post-event local night near the event and
   no supplied products from 2025-03-28 through 2026-07-23. July 2026 follow-up
   observations have unstable strict-QA coverage and cannot support recovery.
7. Q18 nighttime-light changes cannot be attributed here to earthquake
   causation, outage, physical damage, or recovery. The subsequent earthquake
   magnitude conflict (6.4 versus 6.7 in the supplied materials) remains
   unresolved.
8. Q17 accepts the user-provided preprocessed RGB raster; its preceding
   destriping/calibration chain was not rerun. Small green denominators can
   produce large spectral ratios, and fixed thresholds cannot resolve all mixed
   light. No field-validated labels were available.
9. Q17's comparison with earlier RBLI/classification files is an
   implementation-consistency check after a result lock, not an accuracy or
   ground-truth assessment.
10. A Q17 Event Tracker call is conditionally skipped because the scoped request
    is sensor/classification-only. If an event timeline or event-linked temporal
    interpretation is later requested, routing must be reconsidered; no such
    call is fabricated in this package.
